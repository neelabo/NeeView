# 移動先フォルダーパネル

この fork は画像描画、デコード、キャッシュ、アーカイブ読み込みを変更せず、ドッキング可能な `DestinationFolderPanel` だけを追加します。

## クイック分類

fork では `MoveToDestinationFolder1` から `MoveToDestinationFolder9` がネイティブコマンドとして登録され、既定のショートカットは `1` から `9` です。ショートカット、移動先番号、複数ページ方針は通常のコマンド設定で編集でき、スクリプトフォルダーを有効にする必要はありません。

オリジナルの NeeView 46.3 では、`SampleScripts/MoveToDestination1.nvjs` から `MoveToDestination9.nvjs` を **設定 > スクリプト > スクリプトフォルダーを開く** のフォルダーへコピーします。fork の ZIP には重複ショートカットを避けるため、これらのスクリプトを同梱しません。

キー `1` から `9` は現在の「移動先フォルダー」の順序に対応します。フォルダー名やパスの変更ではスクリプト編集は不要ですが、並び替えると番号の対応も変わります。

数字キーが別のコマンドまたはスクリプトに割り当て済みの場合は、分類スクリプトを使う前に NeeView のコマンド／スクリプト設定で競合を解消してください。

フォルダーから開いた実ファイル画像だけを移動できます。アーカイブ、PDF、プレイリストのページは対象外です。`MultiPagePolicy` は `Once` のため、現在のメイン画像だけを移動します。

## パネルと履歴

パネルには設定済みの移動先フォルダーが件数制限なしですべて表示されます。リストがパネルの高さを超えると、ドラッグ可能な垂直スクロールバーが表示されます。行をクリックすると現在のメイン画像を移動します。`UndoDestinationMove` と `RedoDestinationMove` の既定ショートカットは `Ctrl+Z` と `Ctrl+Y` で、通常のコマンド設定から変更できます。

移動履歴はセッション中のメモリだけに既定で最大 300 件保持されます。同じ設定セクションで 0～1000 件に変更でき、0 にすると移動履歴を無効にできます。キャンセルまたは失敗した操作は履歴を変更しません。ファイルが見つからない場合や上書きをキャンセルした場合も、undo/redo の先頭履歴は保持されます。

## 独立プロファイル

ZIP パッケージを使用すると実行ファイルの隣の `Profile` に fork の設定を分離できます。または、NeeView 起動前に既存の絶対パスを `NEEVIEW_PROFILE` に設定します。`C:\Program Files\WindowsApps` 内のファイルは置き換えないでください。

Store 版から全設定を `.nvzip` として一度エクスポートし、fork 側へインポートできます。インポート後のプロファイルは相互に独立します。
