Открыть... Выбрать и открыть файл изображения или сжатый архив.

Добавить в плейлист Добавить текущую страницу в плейлист или удалить из него.
Открыть в Проводнике Открыть папку с просматриваемым файлом в Проводнике Windows.
Открыть во внешнем приложении Выбрать внешнее приложение для открытия отображаемого изображения.
Вырезать Вырезать файлы в буфер обмена.
Копировать Копировать файлы в буфер обмена.
Вставить Вставить файлы или изображения из буфера обмена.
Копировать в папку Выбрать папку для копирования отображаемого изображения.
Переместить в папку Выбрать папку для перемещения отображаемого изображения.
Сохранить как... Сохранить изображение в файл.
Печать... Распечатать изображение.
Удалить Удалить файл. Сжатые файлы в архивах не могут быть удалены.
Выход Завершить работу приложения.
