# Инсталлятор (Installer)

Дистрибутив с мастером установки (Installer).

* Профиль сохраняется в `%LOCALAPPDATA%\NeeLab\NeeView`.
* Доступен выбор ассоциаций файлов во время установки.
* Поддерживает автообновления.
