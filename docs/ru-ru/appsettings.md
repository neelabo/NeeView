# Файл настроек приложения

В этом разделе описывается конфигурационный файл **NeeView.settings.json**, определяющий поведение приложения.

> [!WARNING]
> Настройки оптимизированы для данного дистрибутива. Обычно редактировать их не требуется.

### PackageType

Тип пакета приложения.  
Приложение работает в соответствующем режиме.

### Revision

Для отображения.  
Номер ревизии в репозитории исходного кода.

### SelfContained

Для отображения.  
Указывает, собран ли пакет как автономный (Self-contained).  
Значение `false` означает зависимость от установленного .NET framework (-fd).

### UseLocalApplicationData

Сохранять профиль в **LocalApplicationData**.  
Если `false`, профиль сохраняется в папке с исполняемым файлом.  
Для дистрибутивов Msi и Appx значение установлено в `true`.

### TemporaryFilesInProfileFolder

Создавать временную папку по умолчанию внутри папки профиля.  
Если `false`, используется системная временная папка.

### TrimSaveData (v46.0+)

Предотвращает запись значений свойств по умолчанию в файл конфигурации.  
Если установлено в `false`, записываются абсолютно все свойства.

### PathProcessGroup

Путь к приложению используется для ограничения повторного запуска.  
Если `false`, для идентификации используется только имя процесса.

### SoftwareRendering (v46.0+)

Если `true`, рендеринг WPF выполняется только программно (Software Rendering).  
Производительность графики при этом снижается.

### Watermark

Отображение водяного знака для типа пакета.  
Для версий Alpha и Beta установлено в `true`.

### LogFile

Для разработки.  
Указывает путь к файлу логов.  
Если `null`, лог-файл не создаётся.
