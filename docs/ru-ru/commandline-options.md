# Параметры запуска NeeView

Версия 46.0

### Использование

    > NeeView.exe [Параметры...] [Файл или Папка...]

### Параметры

Параметр|Описание
--|--
\-b, \-\-blank|Запуск без открытия файла изображения
\-h, \-\-help|Отобразить данную справку
\-l, \-\-language=\<строка\>|Временный язык интерфейса (например, 'ru-RU' или 'en-US')
\-n, \-\-new\-window[=off\|on]|Запускать ли в новом окне
\-o, \-\-folderlist=\<строка\>|Указать расположение книжной полки
\-r, \-\-reset\-placement|Сбросить координаты окна
\-s, \-\-slideshow[=off\|on]|Запускать ли слайд-шоу при старте
\-v, \-\-version|Показать информацию о версии
\-x, \-\-setting=\<строка\>|Указать путь к файлу настроек "UserSetting.json"
\-\-clear\-registry|Очистить записи реестра для NeeView
\-\-script=\<строка\>|Выполнить указанный файл скрипта при запуске. Можно указать файл из папки скриптов: 'script:\foobar.nvjs'
\-\-tray[=off\|on]|Запустить приложение в системном трее
\-\-window=\<normal\|min\|max\|full\|desktop\>|Запустить с указанным состоянием окна
\-\-|Обозначает конец списка параметров. Последующие аргументы считаются именами файлов.

### Примеры

`> NeeView.exe -s E:\Pictures`

`> NeeView.exe -o "E:\Pictures?search=foobar"`

`> NeeView.exe --window=full`

`> NeeView.exe --setting="C:\MySetting.json" --new-window=off`
