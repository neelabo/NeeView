# Спецификация файла темы v1.0.0

Определяет цветовую схему элементов управления для темы в формате JSON.

В ZIP-версии приложения файлы тем по умолчанию расположены в папке `Libraries/Themes`. Используйте их в качестве образца при создании собственной темы.

### Элемент: Format

Фиксированное значение, указывающее, что данный файл является файлом темы.

    "Format": "NeeView.Theme/1.0.0",

### Элемент: FormatManual

URL данной страницы. Приложение игнорирует этот параметр.

    "FormatManual": "https://neelabo.github.io/NeeView/ru-ru/theme.html",

### Элемент: BasedOn

Наследование определений. Необязательный параметр.

Если указано "themes://", ссылка ведёт на стандартный файл темы. Если указано только имя файла, ссылка ведёт на файл в той же папке.

Наследование позволяет переопределить только те цвета, которые требуется изменить.

Пример наследования темной темы по умолчанию:

    "BasedOn": "themes://DarkTheme.json",

### Элемент: Colors

Ассоциативный массив «Определений цветов элементов управления».

    "Colors": {
        :
    }

## Определение цвета элемента управления

### Ключ (Key)

Пример: `Button.MouseOver.Background`

Ключи состоят из букв и точек. Они содержат имя элемента управления, состояние, атрибут и указывают, к чему применяется цвет. Последняя часть является «атрибутом» и важна для механизма резервного выбора (Fallback).

### Значение (Value)

Формат:

    [Цвет|КлючСсылки](/Прозрачность)

#### Цвет

Цвета указываются в формате .NET: `"#AARRGGBB"`, `"#RRGGBB"`, `"#ARGB"`, `"#RGB"`, имя цвета (например, `"Red"`).

Пример: цвет фона окна чёрный:

    "Window.Background": "#FF000000",

#### Ключ ссылки (ReferenceKey)

Указывает другой ключ вместо цвета, чтобы использовать его значение.

Пример: цвет рамки IconButton.Pressed такой же, как у Control.Accent:

    "IconButton.Pressed.Border": "Control.Accent",

#### Прозрачность (Opacity)

Указывается через `/[0.0-1.0]`.  
Если опущено, цвет будет полностью непрозрачным (`/1.0`).

Пример: неактивный заголовок окна полупрозрачный на 50%:

    "Window.InactiveTitle": "Window.ActiveTitle/0.5",

## Резервный выбор (Fallback)

Автоматически подбирает цвет-заменитель, если ключ или значение не определены.

- Если атрибут `Foreground` не определён для AAA, используются данные `Window.Foreground`.
- Если атрибут `Background` не определён для AAA, используются данные `Window.Background`.
- Если другие атрибуты AAA не определены, используется `AAA.Background`.
