Обзор

Расширяйте функционал команд с помощью скриптов. Вы можете изменять настройки, выполнять несколько команд одновременно или выполнять их как отдельные команды с изменёнными параметрами.

По умолчанию скрипты отключены. Настройте и включите их на странице "Скрипты" в Настройках.

  • Грамматика скриптов — JavaСкрипт.
  • Jint is used for the script engine.
  • Расширение файла — .nvjs.
  • Кодировка символов — UTF-8. Рекомендуется без BOM.

Вы можете определять команду с помощью комментариев в верхней части файла. Ключи не чувствительны к регистру.

Командные скрипты

Если файл скрипта размещён в папке скриптов, его можно использовать как команду. Один файл — одна команда.

  • Горячая клавишаs can be set in the "Редактировать команды" of the Параметры like normal commands.
  • Имя файла становится именем команды.

Событийные скрипты

Скрипт с особым именем будет выполняться автоматически.
OnStartup.nvjsВыполняется при запуске приложения.
OnКнигаLoaded.nvjsВыполняется при открытии книги.
OnСтраницаИзменено.nvjsВыполняется при изменении вида страницы.
OnСтраницаEnd.nvjsВыполняется при попытке перехода за пределы страницы. Аргумент равен 1 (последняя) или -1 (первая).
OnОкноStateИзменено.nvjsВыполняется при изменении состояния окна.

Консоль

A console for testing scripts. To open it, select "Option > Открыть консоль скриптов" from the menu.

// @name MS Paint

param = {

ВКЛ/ВЫКЛ нерезкой маски

ПереключитьUnsharpMask.nvjs 

// @name Unsharp Mask ON/OFF
// @description Unsharp Mask toggle. Отображениеs a warning when the resize filter is not effective.

if (nv.Настройки.ИзображениеResizeFilter.IsВключитьd) {
    nv.Настройки.ИзображениеResizeFilter.IsUnsharpMaskВключитьd = !nv.Настройки.ИзображениеResizeFilter.IsUnsharpMaskВключитьd
    if (nv.Настройки.ИзображениеResizeFilter.IsUnsharpMaskВключитьd) {
        nv.ShowСообщение("UnsharpMask ON")
    }
    else {
        nv.ShowСообщение("UnsharpMask OFF")
    }
}
else {
    nv.ShowСообщение("ResizeFilter is not active")
}

Если путь к новой открытой книге содержит "English", открывать её влево, иначе — вправо

OnКнигаLoaded.nvjs 

// @name Книга start action
// @description Events when a book is opened

if (nv.Книга.IsNew) {
    if (nv.Книга.Путь.match(/English/) != null) {
        nv.Книга.Настройки.КнигаReadOrder = "СлеваToСправа"
    }
    else {
        nv.Книга.Настройки.КнигаReadOrder = "СправаToСлева"
    }
}
