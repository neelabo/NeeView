Обзор

Расширяйте функционал команд с помощью скриптов. Вы можете изменять настройки, выполнять несколько команд одновременно или выполнять их как отдельные команды с изменёнными параметрами.

По умолчанию скрипты отключены. Настройте и включите их на странице "Скрипты" в Настройках.

  • Грамматика скриптов — JavaScript.
  • Jint используется в качестве движка скриптов.
  • Расширение файла — .nvjs.
  • Кодировка символов — UTF-8. Рекомендуется без BOM.

Вы можете определять команду с помощью комментариев в верхней части файла. Ключи не чувствительны к регистру.

Скрипт команды

Если файл скрипта размещён в папке скриптов, его можно использовать как команду. Один файл — одна команда.

  • Горячие клавиши можно задать в разделе "Настройки > Редактировать команды" так же, как для обычных команд.
  • Имя файла становится именем команды.

Скрипт события

Скрипт с особым именем будет выполняться автоматически.
OnStartup.nvjsВыполняется при запуске приложения.
OnBookLoaded.nvjsВыполняется при открытии книги.
OnPageChanged.nvjsВыполняется при изменении вида страницы.
OnPageEnd.nvjsВыполняется при попытке перехода за пределы страницы. Аргумент равен 1 (последняя) или -1 (первая).
OnWindowStateChanged.nvjsВыполняется при изменении состояния окна.

Консоль

Консоль для тестирования скриптов. Для открытия выберите в меню "Настройки > Открыть консоль скриптов".

Команды только для консоли

clsОчистить экран (Ctrl+L)
exitЗакрыть консоль
help, ?Открыть эту справку по скриптам

Примеры скриптов

Здесь приведены некоторые примеры скриптов. Другие примеры см. в Примерах скриптов NeeView.

Выполнить команду "Внешнее приложение" с временным изменением исполняемого файла и аргументов

OpenMsPaint.nvjs 

// @name MS Paint
// @description Open the file in MS Paint.

param = {
    "Command": "mspaint.exe",
    "Parameter": "\"{File}\""
}
nv.Command.OpenExternalApp.Patch(param).Execute()

Открыть отображаемую страницу в новом окне NeeView

OpenNeeView.nvjs 

// @name Open in NeeView
// @description Open the display page in a new NeeView.

nv.Command.SaveSetting.Execute() // Perform a save to keep settings the same

param = {
    "Command": "{NeeView}", // Special way of writing to indicate the path of NeeView itself
    "Parameter": "-n \"{File}\"",
    "MultiPagePolicy": "Once",
    "ArchivePolicy": "SendArchivePath"
}
nv.Command.OpenExternalApp.Patch(param).Execute()

ВКЛ/ВЫКЛ нерезкой маски

ToggleUnsharpMask.nvjs 

// @name Unsharp Mask ON/OFF
// @description Unsharp Mask toggle. Displays a warning when the resize filter is not effective.

if (nv.Config.ImageResizeFilter.IsEnabled) {
    nv.Config.ImageResizeFilter.IsUnsharpMaskEnabled = !nv.Config.ImageResizeFilter.IsUnsharpMaskEnabled
    if (nv.Config.ImageResizeFilter.IsUnsharpMaskEnabled) {
        nv.ShowMessage("UnsharpMask ON")
    }
    else {
        nv.ShowMessage("UnsharpMask OFF")
    }
}
else {
    nv.ShowMessage("ResizeFilter is not active")
}

Если путь к новой открытой книге содержит "English", открывать её влево, иначе — вправо

OnBookLoaded.nvjs 

// @name Book start action
// @description Events when a book is opened

if (nv.Book.IsNew) {
    if (nv.Book.Path.match(/English/) != null) {
        nv.Book.Config.BookReadOrder = "LeftToRight"
    }
    else {
        nv.Book.Config.BookReadOrder = "RightToLeft"
    }
}

Изменить способ управления видеофайлами

OnBookLoaded.nvjs 

// @name Book start action
// @description Events when a book is opened

if (nv.Book.IsMedia) {
    // Video: click to play/stop, double-click to toggle full screen
    nv.Command.ToggleMediaPlay.ShortCutKey = "LeftClick"
    nv.Command.Script_ToggleFullScreenAndMediaPlay.ShortCutKey = "LeftDoubleClick"
    nv.Command.NextPage.ShortCutKey = "Left"
}
else {
    // Normal: Стандартные настройки
    nv.Command.ToggleMediaPlay.ShortCutKey = null
    nv.Command.Script_ToggleFullScreenAndMediaPlay.ShortCutKey = null
    nv.Command.NextPage.ShortCutKey = "Left,LeftClick"
}

// @name Полный экран & video playback
