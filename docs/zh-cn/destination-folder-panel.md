# NeeView 快速分类薄 Fork

此版本新增目标文件夹面板、移动/复制模式、移动历史与快捷分类命令，不修改图片渲染、解码、缓存或归档读取链路。

## 原版 46.3 脚本

将 `SampleScripts/MoveToDestination1.nvjs` 至 `MoveToDestination9.nvjs` 放入 NeeView 的脚本目录。Store 版可在“选项 > 脚本 > 打开脚本文件夹”确认实际目录。

原版 46.3 使用脚本时，数字键 `1` 至 `9` 始终对应 Destination Folders 当前顺序的前九项。目录改名或换路径无需修改脚本；调整目录顺序会同步改变数字映射。如果数字键已被其他命令占用，请先在命令或脚本设置中解决快捷键冲突。

原版 46.3 没有模式设置，根目录下的示例脚本始终移动图片。fork 专用的模式脚本位于 `SampleScripts/Fork/`，它们会读取面板的模式设置。目标只接受直接从普通文件夹打开的真实图片；压缩包、PDF、播放列表、媒体和快捷方式页面会被拒绝。`MultiPagePolicy` 固定为 `Once`，每次只处理主当前图片。

## 面板与撤销/重做

`DestinationFolderPanel` 默认出现在右侧，可拖动、浮动、隐藏。面板上半区显示“管理目标文件夹”中手动添加的持久化目录；下半区单独显示当前主图片所在目录的直接子文件夹，不递归，也不写入持久化目标目录配置。两组都不限制数量，各有独立滚动条；中间分界线可上下拖动，比例会保存到面板配置，在重新打开面板或重启后恢复。手动刷新只更新下半区，不会覆盖上半区配置。

“自动刷新子文件夹”开关默认开启，并写入配置；仅在当前图片所在目录切换时枚举一次，不轮询，同目录翻页不会重复扫描。关闭后可用手动刷新按钮更新下半区；切换目录时会清除旧目录的子文件夹，避免误分类。新建文件夹会在当前图片目录下创建直接子文件夹，并刷新下半区，不会自动加入手动管理列表。

旧版“刷新”曾把子文件夹直接保存为全局目标目录，升级后这些历史条目会留在上半区；程序无法可靠判断它们是手动添加还是旧版刷新产生，因此不会自动删除。若看到重复目录，可在“管理目标文件夹”中按需清理，上半区的其他手动配置不会被新刷新逻辑改写。

面板底部将“移动 / 复制”和“自动刷新”两个开关排在同一行，完整说明可通过悬停提示查看；模式选择也会写入配置。单击任一区域的目录或新建目标文件夹后，当前主图片按所选模式处理。移动后会继续显示下一张；复制保留源图和当前页面，可继续复制到其他目录。

Fork 已内置 `MoveToDestinationFolder1` 至 `MoveToDestinationFolder9` 原生命令，默认快捷键为 `1～9`，无需启用脚本目录。数字键仅对应上半区手动管理目录的前九项，下半区子文件夹不占用数字映射；内置数字键也遵循面板的移动/复制模式。每个命令的快捷键、目标目录序号和多页策略都可在普通命令设置中修改。原始 `MoveToFolderAs` 命令始终执行移动。若现有 Profile 已启用同名数字键脚本，可改用 `SampleScripts/Fork/` 中的版本；交付 ZIP 不预装快捷脚本，以免与内置命令产生重复快捷键。

全局命令 `UndoDestinationMove` 和 `RedoDestinationMove` 默认快捷键分别为 `Ctrl+Z`、`Ctrl+Y`，可在普通命令设置中修改。历史仅记录移动，不记录复制。历史仅保存在当前会话内，默认最多记录 300 次成功文件移动；容量可在同一设置区调整为 0～1000，设为 0 会关闭移动历史。退出后历史清空。取消、失败、源文件被外部移动或取消覆盖时，历史栈顶保持不变，处理问题后可以重试。

撤销时若原路径已有同名文件，会明确询问“覆盖/取消”，不会静默覆盖。若用户仍在原文件夹浏览，成功撤销后会重新加载并定位恢复的图片；若已切换到其他位置，则只恢复文件并提示。

## 独立 Profile 与迁移

x64 ZIP 使用程序目录旁的 `Profile` 文件夹，与 Store 版配置完全隔离。不要修改或替换 `C:\Program Files\WindowsApps` 下的任何文件。

如需迁移现有设置，请先在 Store 版中“导出全部设置”为 `.nvzip`，再在 fork 中导入一次。导入后两套 Profile 不再共享，后续修改互不覆盖。

## 构建与打包

在仓库根目录执行：

```powershell
.\MakePackage\BuildDestinationForkPackage.ps1
```

脚本使用官方 x64 发布配置，验证供原版使用的九个脚本映射，复制中文说明并在 `MakePackage\Deliverables` 生成 ZIP 与 SHA-256 文件。
